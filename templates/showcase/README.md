# Lantern Reach

Original modkit showcase content by Nugwa. Open this folder in Mod Studio or copy it into the Mods folder as `showcase`. Create a fresh character and follow the route from Lantern Harbor through the Shifting Garden to Lens Court. Complete the collection and boss objectives for a Beacon Seal.

The full walkthrough is [in the engine docs](../../docs/modkit/showcase-walkthrough.md). It maps each system to its file and lists what to inspect in the game window. Install the optional `showcase-notes` sibling add-on for a route overlay; this manifest explicitly approves it.

All included art, names and story are original. The table patch refers to the player's installed data instead of redistributing its tables or assets. Character copying is disabled for this independent progression.
