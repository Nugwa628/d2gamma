# Studio map editing

Open a full mod or gameplay add-on and choose **Map editor**. Set the converted install and installed-mod paths above the editor to resolve assets inherited from the mod stack, then load maps. **New map + generated tiles** creates a source map and a distributable grey tile library entirely from generated pixels. Save writes these inside your project. Existing game files are never copied into a template.

Choose a level and source variant. Paint floors or walls with the tile brush; Erase clears cells. Add floor/wall layers as needed (two floor and four wall layers maximum). Pan with middle/right drag, zoom with the wheel, or use Fit. The preview uses the game's shared tile assembly, isometric draw ordering and CPU rendering.

Entry, Warp, Object, Spawn region and Preset tools place annotations by clicking the map. Expand **Level rules and placements** to adjust positions, destinations, class IDs, modes, rectangular spawn bounds, counts and preset paths, or remove a placement. Warp slots are 0–7 and destinations must have return links. Coordinates and world offsets use tiles. New level IDs also need the corresponding table rows, and cross-act travel belongs in `acts.toml`.

Use **Import sidecar** for a DS1 already inside your project's `files/data/global/tiles/` directory, relative to that directory. It becomes available to source variants and preset stamps. Set the declared size to match the imported DS1 dimensions without its final border. Cloning a level shares its source variants; import a separate DS1 when you want independent painting. Libraries are listed in each level's tile paths. **Tile library · pixels and collision** edits palette indices in individual blocks and flags in the 5×5 collision grid. Index 0 is transparent; the generated library has walkable floor groups 1/3 and blocking wall group 2. Imported tile art is displayed as palette indices in greyscale; the game's act palette supplies its in-game colors.

Generation can be Preset, Maze or Outdoor. Source painting edits the source DS1; random generation replaces its grids before stamps and placements, so use **Show seeded layout** to see its result. Select the generator brushes using the cell-value encoding described in [random levels](random-levels.md).

**Seed previews** rolls 32 consecutive layouts by default, with a range of 1–64. Work runs off the UI thread. Click a thumbnail to inspect its exact seed on the main canvas. The same realization code drives the game and the headless `Mod-Studio seed-preview` command. Thumbnails allocate bounded images rather than full-resolution maps.

Save validates the registry and every source variant before writing. Painting, placement, rule and tile-library edits support Undo/Redo. Writes stay in the current project, so editing an inherited asset creates a project override. External changes to edited files stop a save and preserve your in-memory work. Return to the start page and opening another project are guarded while map edits are unsaved; Closing Studio offers Save, Discard and Keep editing when maps are unsaved. Map saves stage all files before replacing them, and restore replaced files on a rename failure.

**Play**, **Check** and **Package** save map edits before launching their tools. Run Check before sharing: it streams real collision data, checks graph connections and return links, and verifies entry-to-warp/spawn reachability. Random maps are sampled over 32 seeds; passing that sample is not proof for every possible seed. Stateful objects can change collision during gameplay and remain a playtest concern. A human should playtest map art, object interactions, spawn balance and the intended travel route with the author's own assets.
